# Simulador de API Gateway

Juego interactivo para practicar **ruteo de API Gateway**: predicados, filtros, orden de las rutas y reescritura de paths.
Ocho niveles, un laboratorio libre y una guia rapida.

Material de la clase de Backend del 06/10 (Apunte 19 - API Gateway).

Es un unico archivo HTML, sin backend: se puede abrir local o usar la version publicada.
