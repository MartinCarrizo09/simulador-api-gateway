Predicados: ¿esta ruta se activa?

      
path("/api/x/**")
el path empieza con /api/x. ** es "todo lo que siga" (también nada)

      
path("/api/x/*")
exactamente un tramo más: /api/x/7 sí, /api/x/7/y no

      
method("GET")
solo ese verbo HTTP

      
header("X-Version", "2")
el pedido trae ese header con ese valor

      
host("api.gym.com")
el pedido se hizo a ese host

      
query("debug")
la URL trae ese parámetro

      
before(…) / after(…)
antes o después de una fecha

      
.and() / .or()
combinar predicados


    
Filtros: ¿qué le cambio?

      
rewritePath(a, b)
cambia el path antes de reenviarlo (pre-filtro)

      
addRequestHeader(n, v)
agrega un header al pedido que llega al servicio (pre-filtro)

      
addResponseHeader(n, v)
agrega un header a la respuesta que vuelve al cliente (post-filtro)

      
setStatus(…)
cambia el código de respuesta

      
stripPrefix(1)
saca el primer tramo del path

      
requestRateLimiter(…)
limita cuántos pedidos por segundo

      
Si ninguna ruta coincide, el gateway responde 404 sin llamar a nadie. Si el servicio está caído, responde con un error (500 en el práctico).


    
Una ruta completa


.route("maquinas", r -> r.path("/api/maquinas/**")
        .and().method("GET")
        .filters(f -> f.addResponseHeader("X-Gateway", "fuerzagym"))
        .uri("http://localhost:8081"))

      
id · predicados · filtros · destino. Va dentro de builder.routes() … .build(), en un @Bean RouteLocator.
